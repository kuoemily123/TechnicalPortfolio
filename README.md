# Emily Kuo – Engineering Portfolio

One-page portfolio site. All text is in `index.html`; the pictures and the poster PDF sit in the same folder.

## Update the site
1. Open `index.html` on GitHub and click the pencil icon (Edit).
2. Change text, or copy a whole project block (see the comment at the top of the file).
3. Click **Commit changes**. The live site refreshes in 1–2 minutes.

## Add or replace images
Upload the image file to the repository (Add file > Upload files), then reference it in `index.html`, for example:
`<img src="my-photo.jpg" alt="Describe the image">`
